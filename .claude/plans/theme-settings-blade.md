**Legend:**
- `[●]` = Toggle ON (green)
- `[○]` = Toggle OFF
- `✓` = Selected item
- `[<] [>]` = Arrow navigation buttons
- `◄─scroll─►` = Horizontal scroll/drag area
- Circle patterns (`○ ○ ○`) = Circle Ripples animation overlay
- Grayed items = Disabled when layer toggle is off

## Overview

Enhance the ThemePage blade in ProfileModal to allow users to configure background layers with:
- **Upper section**: Stacked horizontal carousels for each layer type (base image, animations)
- **Lower section**: Live preview showing combined background layers
- **UX Pattern**: Preview + Apply (changes preview locally, Apply button commits)

## User Requirements Confirmed

| Requirement | Decision |
|-------------|----------|
| Layer toggle | Toggleable + Selectable (on/off AND which variant) |
| Preview type | Live preview with real-time animations |
| Apply behavior | Preview + Apply button (recommended for batch visual changes) |
| Navigation | Arrow buttons + scroll/drag |

## Architecture

```
ThemePage (refactored)
├── LayerCarouselSection (upper ~60%)
│   ├── LayerCarousel - "Background" (base images)
│   │   ├── CarouselArrow (left/right)
│   │   └── CarouselItem[] (thumbnails)
│   ├── LayerCarousel - "Circle Ripples" (with toggle)
│   └── LayerCarousel - "Water Ripples" (with toggle)
└── LivePreviewSection (lower ~40%)
    └── BackgroundPreview (renders selected layers)
```

## Key Components

### 1. LayerCarousel

```
┌────────────────────────────────────────────────────────┐
│  [Toggle] Layer Name                        [<]  [>]   │
├────────────────────────────────────────────────────────┤
│  [Thumb1] [Thumb2] [Thumb3] [Thumb4] ...   (scroll)   │
└────────────────────────────────────────────────────────┘
```

Features:
- Header row: optional toggle + layer name + arrow buttons
- Track: `overflow-x: auto` with smooth scroll + drag support
- Disabled state when layer toggled off (items grayed)
- Audio: `useAudioManager` for hover/click sounds

### 2. CarouselItem

- Thumbnail container (16:9 aspect for backgrounds, 1:1 for animations)
- Selection state: green border glow (`--color-brand-primary`)
- Hover: scale 1.05, Framer Motion
- Disabled: opacity 0.4 when layer off

### 3. LayerToggle

- Xbox-style toggle (44x24px track, 18px thumb)
- Green accent when enabled
- Audio feedback on toggle

### 4. LivePreview

- Miniature BackgroundComposer
- Renders:
  - BaseLayer with selected image
  - Animation layers from registry (only enabled ones)
- Note: WaterRipples may need special handling (requires `.crt` container)

### 5. useThemePreviewState Hook

```typescript
interface ThemePreviewState {
  baseImageId: string;
  animationStates: Map<AnimationLayerId, boolean>;
  isDirty: boolean;
}

// Returns:
{
  previewState,
  setBaseImage,
  toggleLayer,
  applyChanges,  // calls context setBackground + setAnimationLayerEnabled
  resetToSaved,
  isDirty
}
```

## Integration Points

### Apply Button Wiring

ProfileModal's external footer has an "Apply" button for the Theme page. Need to:
1. Create ref/callback mechanism in ThemePage
2. Wire footer button onClick to trigger `applyChanges()`

Option: Use context or imperative ref handle:
```typescript
// In ProfileModal.tsx theme page config
const themePageRef = useRef<{ apply: () => void }>();
// Footer action: onClick={() => themePageRef.current?.apply()}
```

### Existing Context Integration

Use `BackgroundContext` methods:
- `setBackground(backgroundId)` - for base image
- `setAnimationLayerEnabled(layerId, enabled)` - for animation toggles
